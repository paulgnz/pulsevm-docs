# XPR→PulseVM Cutover Testing

The XPR 1:1 demo network, which ran an import of XPR Network testnet state on PulseVM, was retired on 2026-10-19. Its endpoints are offline.

The XPR→PulseVM cutover is now being tested in rehearsals. Public test endpoints will be published on [Network Endpoints](/network/endpoints) when available.
